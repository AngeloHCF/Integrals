# Interactive Integration Practice

## How to use it

1. Open `output/pdf/integration-techniques-interactive.pdf` in Adobe Acrobat Reader.
2. Click any blue integral to show its answer.
3. Click the same integral again to hide the answer.

> If clicking does nothing, download the PDF and open it in Adobe Acrobat Reader. Most browser PDF viewers do not support the answer toggles.

## Rebuild the PDF

After editing `main.tex`, run:

```powershell
latexmk -pdf main.tex
```
